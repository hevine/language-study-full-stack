# 韩语 3 级精读课通用教案（TOPIK 3 级）

> **本级重心：冠形词形与长名词短语的切分 ＋ 段落内的指代链。** 3 级的句子不再只是"分句相连"，而是把一整层意思压进一个名词短语，中心名词在最后；读不出短语边界，后面所有推断都会建立在错的主语上。

## 一、教材分析

3 级材料的变化不在生词，而在"一个名词前面能挂多少东西"。汉语说"我昨天在图书馆遇到的那个人给我的书"，靠"的"层层左挂；韩语写成 어제 도서관에서 만난 사람이 준 책，中心名词 책 在最后，修饰它的是一整串带冠形词尾的动词短语，且没有关系代词可用。因此本级的精读主线是"括号法切分"：把每个冠形结构括起来，找出中心名词，再判断修饰层之间的时制关系（-은 过去、-는 现在、-(으)ㄹ 将来/推测）。同时，段落层面要能追踪 이/그/저 与 그런/그렇게 的指代对象，因为 3 级文章开始依赖指代来省字。取舍上：本级只做短语层与段落层，让步强度、名词化命题（-ㅁ/-음）与论证结构归 4 级，本级不涉及。

## 二、学情分析

学生已能处理复句，但一遇到长名词短语就从左往右逐词译，常把第一个名词误当中心。三类常见错因：其一，把 어제 만난 사람이 준 책 译成"昨天见了那个人给的书"，中心名词错位。其二，冠形词尾的时制读不出，把 -(으)ㄹ 的将来/推测读成"已经发生"，导致整句时间错乱。其三，段落里 이/그 一律译成"这/那"，不回指具体对象，读到第三句就不知道"그것"指什么。这些错都发生在"边界"上——短语边界与指代边界。

## 三、教学目标

（韩语未列入本目录的学段学科，以下目标为暂拟，不宣称已对齐课程标准。）

1. 能用括号法切分 4 层以内的长名词短语，标出每一层的冠形词尾与中心名词，并译成通顺汉语。
2. 能依据冠形词尾（-은／-는／-(으)ㄹ／-던）判断修饰内容的时制与情态，说明同一短语换词尾后意思的变化。
3. 能在段落中画出指代链，说明 이／그／저 与 그런／그렇게 各自回指的具体内容。

## 四、教学重难点

**重点：中心名词永远在短语最后，切分顺序是从右往左。** 어제 내가 만난 사람이 준 책 的中心是 책；사람 是"준"的主语，不是中心。教法上固定为三步：先找最右边的名词→再找紧挨它左边的动词词尾→最后把整块括起来。

**难点：-(으)ㄹ 的双重身份。** 它既可表将来（내일 갈 사람），也可表推测或性质（비 올 것 같아요／먹을 만한 곳）。学生只记"将来"就会误读。本课用三句对照（갈 사람／온 사람／오는 사람）建立"词尾定时制"的直觉，再用"먹을 만한"点出推测用法。

## 五、教学流程

长句歧义诊断 → 括号法三步 → 冠形词尾时制 → 文化说明文标注 → 嵌套短语与指代链迁移 → 收束 → 当堂检测 → 作业布置

## 六、教学方法

括号切分演示、词尾对照三连句、指代箭头、分译比较、同伴互查

## 八、教学过程

| 教学环节（用时） | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|
| 复习导入（8 分钟） | 出示一句 12 词长句：어제 도서관에서 만난 사람이 나에게 준 책은 아주 재미있었어요.<br>提问："这句话讲的是谁？是사람、책，还是나？"<br>把三种答案都写在黑板上，不立即纠正。 | 先按顺序直译，再说"我认为中心是＿＿"。<br>预设回答："中心是사람"或"是나"。 | 用真实歧义暴露"中心名词错位"这一核心难点。 |
| 新知建构（24 分钟） | 板书括号法三步：①找最右名词 책；②看左边动词 준 的词尾；③把 [어제 … 만난 사람이 준] 整块括起。<br>再做词尾对照：온 사람（已来）／오는 사람（正在来）／올 사람（将来）；-던（过去回想）。<br>补 -는 것 与 -기 的差别：-는 것 指具体事件，-기 偏"做某事"这一事实（읽는 것이 좋아요／읽기가 어려워요）。 | 在学案上给 3 个短语画括号并写中心名词。<br>预设错误：把第一个名词括成中心。 | 把"读长句"变成可执行的切分动作，而非靠语感。 |
| 示范精读（14 分钟） | 出示 320 字文化介绍（韩屋居住方式），逐句做括号切分，只括主干，不括插入的时间地点。<br>提问："이 글에서 '이러한 방식'은 앞의哪一句？"<br>示范指代链画法：이런 → 上一句的"共用院子"；그 → 前文已提的"韩屋"。 | 跟做两段，标中心名词与指代箭头。<br>预设回答："이러한 指上一句整件事。" | 示范"短语边界＋指代边界"同时处理，形成双线阅读。 |
| 应用迁移（22 分钟） | 任务一：给 5 个层层嵌套的短语（含 -던、-(으)ㄹ），要求切分并译成汉语，其中 2 个故意设中心名词陷阱。<br>任务二：给一段 150 字文字，要求画出 이/그/저 的箭头，并回答"第三句的 그것 指什么"。<br>巡视追问："这个 -(으)ㄹ 是将来还是推测？依据在哪？" | 小组切分、互译；派一人讲一条指代链。<br>预设错误：把 -던 读成"将要"。 | 用陷阱短语检验是否真按三步走，而非凭语感猜。 |
| 课堂总结（8 分钟） | 请学生复述括号法三步与三种冠形词尾的时制。<br>补一句："短语看右端，段落看指代。" | 口头补全板书。 | 让学生自建流程，暴露仍从左读的习惯。 |
| 当堂检测（10 分钟） | 3 题切分并译（含 1 题 -(으)ㄹ 推测）；3 题词尾时制判断；2 题指代回指。<br>判据：切分 3 题全对标 3 分；能说出 -(으)ㄹ 两种用法之一为达标。 | 独立完成，交换批改。 | 对应三条目标，重点检验边界判断。 |
| 作业布置（4 分钟） | 必做：从教材找 1 段 150 字文字，画指代链并标 3 个长短语的中心名词。<br>选做：把 2 个长短语改写成两个短句，比较语气差异。 | 记录要求。 | 迁移到自主阅读，训练"先切后译"。 |

## 九、板书设计

```
【切分三步】 ①最右名词 → ②左边动词词尾 → ③整块加括号
   [어제 [내가 만난] 사람이 준] 책   ← 中心＝책

【冠形词尾＝时制】 -은 过去 ｜ -는 现在 ｜ -(으)ㄹ 将来·推测 ｜ -던 过去回想
                    ↓
【指代链】 이(近·刚提) → 그(前文已知) → 저(远指)
          이런/그런/그렇게 ＝ 回指一整句或一类做法
                    ↓
【段落】 主题句多在段首；说明文结论常后置 → 先标主题句再读细节
```

## 附录 A　课后题讲评表

| 错误表现 | 真实原因 | 课堂对策 |
|---|---|---|
| 中心名词取第一个 | 按汉语"的"字结构从左读 | 强制三步：先找最右名词 |
| -(으)ㄹ 全读成"将要" | 只记一个义项 | 三句对照 갈/온/오는 사람 |
| -던 读成将来 | 与 -(으)ㄹ 混淆 | 加"回想"标签，配 시간이 흐른 후 语境 |
| 第三句的 그것 指不明 | 不回指，逐句独立译 | 画箭头，箭头必须落在具体短语上 |

3. 指代：画出下段中 이/그 的箭头，并写出"그러한 생각"指什么。

## 附录 D　分层任务与评价依据

| 层级 | 任务 | 评价依据 |
|---|---|---|
| 基础 | 3 个短语切分并写出中心名词 | 中心名词正确，括号边界不错位 |
| 标准 | 把 2 个长短语分译成两句，并说明分译后丢了什么信息 | 能指出"修饰关系被拆散"这一代价 |
| 挑战 | 自写 1 句话，要求含两层修饰且中心名词不在句首 | 括号法能复原，时制不错乱 |

**时间预案**：若括号法建构超时，文化说明文只做前两段，指代链移到课后；若学生切分顺利，可加"同一短语换 -(으)ㄹ 后意思如何变"的口头对比，不新增结构。

**评价口径**：本级不评价"译得雅不雅"，只评价边界——短语中心是否找对、指代箭头是否落在具体短语上。译文通顺但中心名词错位，判未达标。
