# N5 日语精读课通用教案

> 通用模板：适配任一 N5 精读篇目（会話文、短文 200–300 字）｜2 课时（90 分钟连排，可拆 2×45 分钟）｜换材料只需改附录四所列五处。

| 项目 | 内容 |
| --- | --- |
| 课程名称 | 日语精读（N5） |
| 选用教材 | 不指定版本，适配同级任一精读篇目（通用模板） |
| 教学章节 | 同级任选一篇会話文或短文，2–4 段 |

## 一、教材分析

N5 精读材料多为 200–300 字的会話文或短文，2–4 段，话题集中在自我介绍、家庭、日常作息、购物、交通与学校生活。本课处在「语音与基本句型」向「成段理解」过渡的位置：句子短、以「です・ます」体为主，信息全部显性呈现，几乎不需推断。学科关键点在于——这一阶段的阅读困难很少来自词义，而来自「音—形—义」尚未绑定：学生能查出生词的意思，却读不出句子的骨架。因此本课的取舍是：不追求讲完所有生词，而是用一段完整的话把「断句—找谓语—认助词」这条流程走通，为后续成段阅读留下可重复的动作。

## 二、学情分析

知识基础：已掌握平假名、片假名与约 100–200 词，能认读「です・ます」体与基本助词，活用形只在单词层面熟悉。能力基础：单句能读懂，成段阅读时依赖逐词翻译，读完全文说不出整句意思。思维基础：习惯「先翻成中文再理解」，缺少用日语直接抓骨架的意识。

常见错因（预设，非本班事实）：①长音、促音、拗音读不准，读出的句子与听到的对不上；②は／が 混用，判断不出主语；③に／で 混用，场所与时间错位；④否定与过去形读到句末才发现意思相反。纠正不靠讲规则，而靠「朗读先行＋助词换位＋骨架还原」三个动作。

## 三、教学目标

**语言知识：** 能准确朗读全文，读准长音、促音、拗音与句末语调；掌握本课 20–30 个新词及 3–5 个基础句型的读音、意义与基本用法。

**读解能力：** 能在不查词典的情况下，从 2–4 段短文中提取「誰・どこ・いつ・何」四类信息并填入信息表；能判断句子的肯定与否定、现在与过去。

**学习策略：** 能按「指读—断句—找谓语」的流程独立处理一个陌生短句；遇生词先看汉字词素与插图推断，不立即查词。

**文化与情感：** 能感受「です・ます」体在日常交际中的礼貌功能，愿意出声朗读、不怕读错。

目标依据：JLPT N5 认定基准（能理解基本的日语）；日语学科不在课程标准目录内，本课目标按可观察行为暂拟。

## 四、教学重难点

**重点：助词功能定位与句子骨架识别。** 学生要建立「は＝主题、が＝主体、に＝时间与到达点、で＝场所与手段、を＝对象」的位置感，并能把句子压成「主题＋补语＋谓语」。由「精读解骨架」环节解决：每句先问「この文の中心になる言葉はどれですか」，把句子压成骨架再还原，每讲一个助词配 3 个替换句，让学生在替换中体会功能，而不是背定义。

**难点：は与が的分工、に与で的区分、活用形在句中的辨认。** 由「朗读正音＋三形对照卡」解决：同一动词的肯定／否定／过去三形横向排列，先读三遍再回原句，让形式差异先变成听觉差异，再变成意义差异；は／が 与 に／で 用「换一个读一遍，意思变了没有」的对比来分辨。

## 五、教学过程

| 教学环节（用时） | 教师活动 | 学生活动 | 设计意图 |
| --- | --- | --- | --- |
| 一、看图预测<br>（8 分钟） | 遮住文字只出示插图，依次问「誰がいますか」「どこですか」「何をしていますか」，把学生说出的名词写在黑板左侧，再揭示标题对比预测。<br>学生只说单词时代为连成句，不要求一次说完整。 | 看图说词，两人一组写出 2 条内容猜测；揭题后圈出猜对的部分。 | 激活已有词汇并制造信息缺口，降低开口门槛，为读解能力目标提供起点。 |
| 二、朗读正音<br>（12 分钟） | 范读一遍、跟读两遍；逐句标出长音、促音、拗音与句末升降；用斜线标断句并追问「ここで息を継ぐのはなぜですか」。<br>某音读不准时单独拆出慢读三遍，再放回原句，不在全班反复纠同一人。 | 跟读并跟标，在自用文本上画断句斜线；同桌互听，指出对方读错的音。 | 先建立语音表征，阻断「字形直接跳向母语」的路径。 |
| 三、速读填表<br>（15 分钟） | 发信息表，说明只找四类信息、不查词典、不逐句翻译；巡桌记录共性错误，不个别打断。<br>核对时问「それはどこで見つけましたか。指で示してください」。 | 独立通读并填表，在文中标出依据词；填不出的先空着。 | 把「读」变成有目标的信息搜寻，检验能否脱离词典获取显性信息。 |
| 四、精读解骨架<br>（25 分钟） | 逐句问「この文の中心になる言葉はどれですか」，把句子压成「誰が｜どこで｜何を｜しました」写在黑板；挑 3–5 个语言点，每个配 3 个替换句；讲一个活用形时出示三形对照卡。<br>追问「この助詞を別のものに替えたら、意味はどう変わりますか」。 | 口头缩句；把骨架还原成完整句；用替换词造句（换人、换场所、换时间）。<br>预设：把「に」当「で」使用。 | 用可替换的骨架替代语法术语，形成可迁移的造句能力，直接对应本课重点。 |
| 五、课后题讲评<br>（15 分钟） | 先不发答案，要求每题在文中画出依据句，再对答案；错题请学生讲判断过程，教师只讲思维卡点，追问「另外三个选项，错在哪里？」 | 独立作答—画依据—同桌互查—全班核对；把错题的依据句抄在学习单背面。 | 把答题训练成「找证据」，暴露的是思维卡点而不是答案。 |
| 六、情境输出<br>（10 分钟） | 给出替换情境（换角色、换地点、换时间），要求用课文句型编 4–6 句对话；给有困难的组半句提示卡。<br>追问「「学校」を「駅」に替えたら、文はどう変わりますか」。 | 两人一组编对话并表演，允许换名词，句型必须来自本课。<br>预设：只会照读课文，此时先要求替换一个名词，逐次增加改动量。 | 检验输入能否转成可用输出，对应语言知识目标的运用层面。 |
| 七、总结与作业<br>（5 分钟） | 归纳本课 3 个句型与 3 个助词，写在黑板右下角；布置作业并说明提交方式。<br>问「今日、一番使えると思った文はどれですか」。 | 每人说出今天记住的 3 句话，记录作业。 | 固化最小可复习单元，让下节课有可抽听的素材。 |

## 附录一　课后题讲评与评价要点

| 题型 | 本级别考查点 | 讲评步骤 | 评价要点 |
| --- | --- | --- | --- |
| 读音与字形题 | 长音、促音、拗音；汉字读音 | 先齐读一遍，再个别读；错的音拆出慢读三遍后回归原句 | 朗读准确率不低于 80%，能指出自己读错的音 |
| 信息定位题 | 誰・どこ・いつ・何 | 三步定位：题干关键词→对应段落→依据句；每题必须画出依据 | 能说出依据句在第几段第几句 |
| 助词辨析题 | は／が、に／で | 替换法：换成另一助词读一遍，问「意思变了没有、变成什么」 | 能说出替换前后意思的差别，而不只是选对 |
| 正误判断题 | 否定形、过去式、数量表达 | 把错项当场改成正确项，让学生自己动笔改 | 能独立改出正确句子，并说明改的是哪个词 |

## 附录三　N5 读解自检清单

- [ ] 我能不看注音把全文读顺，并在该换气的地方换气。
- [ ] 我能在 30 秒内说出这段话讲的是「谁、在哪里、做了什么」。
- [ ] 遇到生词时，我先看汉字和插图猜，而不是立刻查词典。
- [ ] 每答一道题，我都能指出文中的依据句。
- [ ] 我能用本课的 3 个句型说出自己的 3 件事。
