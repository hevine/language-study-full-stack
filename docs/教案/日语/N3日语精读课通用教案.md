# N3 日语精读课通用教案

> 通用模板：适配任一 N3 精读篇目（说明文、随筆、コラム、メール，500–700 字）｜2 课时（90 分钟连排）｜换材料只需改附录四所列五处。

## 一、教材分析

N3 精读材料约 500–700 字，4–6 段，文体开始分化：说明文讲「是什么、为什么」，随筆和コラム讲「我怎么看」。句子层面出现受身、使役、使役受身与敬语体系；段落层面则需要读者自己判断「哪一句是这段话的中心」。本课处在「成段还原」向「篇章结构」过渡的位置，学科关键点是：段落不是句子的堆积，而是一个承担功能（提出、例示、对比、让步、结论）的单位。因此取舍是不逐段翻译，先用功能标签把结构立起来，再回文处理语言点；结构不清时讲再多词义也不解决「每句都懂、全文不懂」。

## 二、学情分析

知识基础：已掌握约 600–900 词，受身与使役的形式能辨认，敬语能读但用得少。能力基础：长句能读通，段落大意常靠「感觉」，概括时倾向照抄原句。思维基础：逐句推进，不习惯先判断段落在做什么，也不主动追指代。

常见错因（预设）：①こ・そ・あ・ど 追丢，尤其中间隔了句子的回指；②使役受身视点乱，说不出「谁让谁、谁受影响」；③把文中引用的他人观点当成作者主张；④要約时删掉了转折与限定，只剩例子。纠正靠「标签—箭头—双栏」三个可见动作。

## 三、教学目标

**语言知识：** 掌握本课 30–40 个新词、5–8 个 N3 句型（如「～ように」「～らしい」「～ばかり」「～ところ」「～によって」），能辨认受身、使役、使役受身的基本视点。

**读解能力：** 能识别每段的主题句与段落功能；能追踪跨句、跨段的指代；能用三句话概括全文主旨；能区分事实陈述与作者评价。

**学习策略：** 用「段落功能标签法」先立结构；用箭头图追踪指代；用三句要約检验自己是否真读懂。

**文化与情感：** 感受句尾语气与敬语所承载的人际距离，理解说明文与随筆在语气上的差别。

目标依据：JLPT N3 认定基准（能理解日常场景中的日语）；日语学科不在课程标准目录内，本课目标按可观察行为暂拟。

## 四、教学重难点

**重点：段落功能与主题句，指代链。** 学生要能给每段贴上一个功能标签，并指出主题句的位置（段首、段末、「つまり／要するに」之后）。由「贴标签速读」环节解决：每段只看首末句判断「在做什么」，标签贴在黑板逐段累积，结构图成形后学生自己就能看出全文推进方式。

**难点：使役受身的视点、作者立场与引用观点的区分。** 由「精读解立场」环节解决：用箭头图写出「谁对谁做了什么」，箭头方向与句中人称对照；引用观点与作者观点分两栏抄在黑板上，回到「～と考えられている」「～のではないか」等语气标记确认归属。

## 五、教学过程

| 教学环节（用时） | 教师活动 | 学生活动 | 设计意图 |
| --- | --- | --- | --- |
| 一、问题切入<br>（8 分钟） | 从文章要回答的问题切入（例：「为什么很多人明明想早睡却做不到」），把学生的解释写在黑板上，再读标题，比较「我们的解释」与「作者的解释」。<br>追问「筆者は、私たちと同じ考えだと思いますか」。 | 用日语说出自己的两个解释；读标题，预测作者立场。 | 用认知落差制造阅读动机，同时预先暴露常识与文本的差异。 |
| 二、贴标签·速读<br>（13 分钟） | 限时 6 分钟通读，只判断每段「在做什么」：提出、举例、对比、让步、结论。示范第一段并说明依据是首句与段末句。<br>追问「この段落は、新しい主張を出していますか、それとも例を挙げていますか」。 | 通读后给每段贴一张标签卡；小组内对有分歧的段说明理由。 | 把段落变成可判断的功能单位，建立结构先于词义的习惯。 |
| 三、找主题句·画指代<br>（17 分钟） | 示范找主题句：段首、段末、总结词之后；讲 3–5 个语言点。用彩色箭头示范一处跨句指代，其余由学生完成。<br>追问「この「それ」は、前のどの部分を指しますか。一語ですか、文全体ですか」。 | 用一色笔标出每段主题句；用另一色笔画指代箭头并写清「これ＝何」。 | 把指代从"感觉"变成可视的连线，支撑读解能力目标。 |
| 四、精读解立场<br>（22 分钟） | 逐段问「这句是事实还是作者的评价」；讲受身与使役受身时用箭头标出「谁对谁做了什么」；把引用观点与作者观点分栏写在黑板上。<br>追问「この使役受身は、誰が一番困っていますか」。 | 给句子标「事実／評価」；用箭头图整理使役受身；把两类观点分别抄到两栏。<br>预设：把引用观点当成作者主张。 | 用分栏与箭头把抽象视点外化，突破本课难点。 |
| 五、课后题讲评<br>（15 分钟） | 先让学生说「这道题问的是全文还是某一段」；再要求把选项逐个回填原文，看是否与原句冲突。<br>追问「这个选项是文中没提，还是与原文相反？」「如果把『すべて』去掉，还对吗」。 | 独立作答；把每个选项回填到对应位置，标「一致／矛盾／文中未提」；小组辩论错项。 | 用回填检验代替排除法，让错误有据可查。 |
| 六、三句要約·互评<br>（10 分钟） | 给出要約规则：删例示、留主张、保留转折；示范把一段压成一句；发互评三条标准。 | 独立写三句要約，与同伴交换，按「含主张／未漏转折／不抄原句」三条互评。 | 用压缩检验真理解，同时训练书面表达。 |
| 七、总结与作业<br>（5 分钟） | 带学生完整复述段落结构图，指出全文转折点；布置作业。<br>问「この文章の「転」はどこですか」。 | 看着结构图口头复述全文脉络。 | 把结构图固化为可迁移的阅读工具。 |

## 六、板书设计

```
《……》                             今日の宿題
────────────────────────────      ○ 要約 3 句（90 字以内）
【段落構造】                        ○ 指代 3 处
 ①提出 → ②例示 → ③対比 → ④譲歩 → ⑤結論
   主題文：＿＿＿＿  主題文：＿＿＿＿
【指代】 これ→（前句） それ→（前段主張） あれ→（共知）
【立場】 事実 ｜ 筆者の評価 ｜ 引用された意見
【要約】 ①何を言う ②なぜ ③だからどうなる
```

## 附录四　通用化替换清单

| 替换项 | 怎么替换 | 换完检查 |
| --- | --- | --- |
| 话题与文体 | 说明文／随筆／コラム／メール可互换，但须有一段承担转折或让步 | 文中至少有 3 处可追踪的指代 |
| 段数 | 4–6 段，每段 4–6 句 | 每段能贴上一个功能标签，标签不重复过多 |
| 语言点 | 2 个句型＋1 个受身或使役＋1 个指代现象 | 每点都能在文中找到实例并做一次替换 |
| 课后题 | 保留四类，总量 8–10 题 | 每题都能回填原文验证 |
| 课时 | 90 分钟为基准；45 分钟只找主题句、要約改为作业 | 压缩后仍保留标签法与课后题 |
