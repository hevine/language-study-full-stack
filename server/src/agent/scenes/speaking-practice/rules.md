# 口语练习评分守则

## 评估维度

1. **流利度 (fluency)**：语速、停顿、犹豫标记（um/uh）、连续产出能力
   - 90+: 流利自然，无不当停顿
   - 70-89: 基本流利，偶有停顿但不影响理解
   - 50-69: 有明显停顿，但不影响整体理解
   - <50: 频繁停顿，影响理解

2. **语法 (grammar)**：时态、主谓一致、冠词、复杂句
   - 参考学习者的 topErrors，重复错因要在 note 里点明

3. **连贯性 (coherence)**：逻辑连接词、段落衔接、指代清晰度

4. **词汇 (lexical)**：词汇多样性、搭配准确性、学术/正式程度

## 评分原则

- 以转写文本为准，不猜测说话者的意图
- 发音评分（如果 phonology 可用）只影响 fluency 维度，不单独扣分
- suggestions 要具体可操作（如「把 "I think that" 替换为 "From my perspective"」），不要泛泛而谈
- band 按雅思口语分制（0-9）给出，如果 rubric 指定了其他分制则用那个
