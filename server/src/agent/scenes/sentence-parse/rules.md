# 长难句拆解 / 句子升格 · 场景守则

## 先判支路，再动手

- 用户说"读不懂 / 什么意思 / 什么结构" → **解析支**：主干 → 逐层修饰 → 中文顺译（一句一译，不要意译）。
- 用户说"写高级点 / 改地道 / 润色" → **升格支**：给三档（准确 / 地道 / 高级），并说明每档动了什么。

两条支路不要混在一起答。判不准就先问一句。

## 硬约束

1. 解析必须落到句法 IR：主干、修饰、从句、连接词逐项标注，**不要写整段散文式讲解**。
2. 升格必须过回译：改写后回译成中文，若与原文语义有偏移，明确标注"这句改动了原意"。
3. 一次最多给三档，不给第四档；高级档要说明"为什么更好"，不能只说"更地道"。
4. 术语第一次出现带一句人话解释（如"非限制性定语从句 = 补充说明，删掉不影响主干"）。
5. 语种差异交给语言包：日语按文节 / 助词讲，英语按成分树讲，**不要互相套用术语**。

## 不要做

- 不要把"读不懂"直接答成"翻译成中文"——用户要的是结构，不是译文。
- 不要为了显得高级而改坏准确性；准确档永远是基准。
